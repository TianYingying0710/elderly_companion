# 老人端 Android 演示版设计

用户已在聊天中确认界面和实现顺序，并授权正式 APK 使用独立模拟数据、默认演示模式。

## 范围

沿用 Vue 3、TypeScript、Vite、Capacitor Android 和独立 FastAPI。四主页面：首页、陪伴、教学、我的。首页两列大入口；教学两列三行大分类；暖色卡片、深蓝字体。二级页面包括课程、学习记录、办事流程、资料、多家人权限、设备、消息、求助记录及字体设置。聊天为微信式文字输入，无语音、真实模型或自动假回复。

模拟数据与页面分离。默认演示模式，顶部始终标记；运行时和构建配置可关闭。关闭后不展示模拟数据，不触发业务调用，不声称实现认证、设备或通知。仅健康检查可调用原有 API。切换模式清空本地演示修改和聊天草稿；刷新恢复初始值。字体偏好仅本次会话有效。

软件 SOS：大字二次确认、手动模拟发送/送达/响应/失败、重试、取消、记录。无自动通知或电话拨号；响应不等于援助到达。取消后可重新发起。演示状态不能泄露到关闭模式。

## 方案选择

已讨论临时 HTML 预览和正式 Vue 落地。用户选择先用临时预览确认视觉，再迁入现有 Vue/Capacitor 工程，保留独立演示数据。直接继续扩展临时 HTML 不利于正式维护；新建原生应用违背既有栈，均不采用。

## 边界

模拟数据授权仅扩大至老人端演示模式，不允许数据库、迁移、seed 或真实业务实现。三端独立，不跨端导入。后端及共享契约不变。外部 SDK/JDK/Gradle 工具不移入仓库。

## 验收

Vue 交互测试覆盖导航、筛选、模式隔离、文字安全、字体及求助状态转换；类型检查和生产构建通过；尝试 Android 构建、既有模拟器安装和截图验证，未完成项如实记录。
