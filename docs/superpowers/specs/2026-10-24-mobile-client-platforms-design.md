# 银龄伴移动端形态与环境解耦设计

## 目标

- 银龄伴源码继续位于 `E:\c2--\code`，不随本机工具目录移动。
- Python、Android SDK、Gradle、模拟器和包管理缓存位于源码仓库外。
- 老人端保留 Vue 3 + TypeScript，通过 Capacitor 生成 Android 应用。
- 监护人端、社区端转换为两个独立的 uni-app + Vue 3 + TypeScript 微信小程序。
- 三端只通过各自 API 客户端调用对应 FastAPI 后端，不跨端导入内部代码。

## 非目标

- 不开发业务页面、认证、数据访问、AI、设备或通知功能。
- 不创建数据库、表、迁移、初始化脚本或模拟数据。
- 不把微信开发者工具、Android SDK、虚拟环境或构建缓存放进仓库。

## 环境边界

- 启动和验收脚本不得把某台电脑的绝对路径作为唯一默认值。
- Python解释器通过命令参数、`SILVER_COMPANION_PYTHON` 或当前激活环境解析。
- pip缓存和临时目录可通过参数或环境变量指定；未指定时使用工具默认值。
- Android工程的 `local.properties` 保持忽略，SDK位置由本机配置提供。
- `.env`、小程序私有AppID配置、构建目录和依赖目录不得提交。

## 客户端结构

### 老人端

`Vue 3 页面 -> API客户端/原生能力适配层 -> Capacitor -> Android工程`

### 监护人端和社区端

`uni-app Vue源码 -> mp-weixin构建输出 -> 微信开发者工具`

微信开发者工具只导入构建输出，不作为源码编辑或保存位置。两个小程序各自维护 `pages.json`、`manifest.json`、依赖、入口和API配置。

## 接口边界

- 前端只依赖环境变量提供的API基址。
- 微信小程序统一通过 `uni.request` 封装访问后端。
- 开发者工具可使用本机开发地址；真机与生产环境必须使用可访问的HTTPS合法域名。
- `code4-shared` 继续只保存稳定、业务中立的Python契约与接口预留。

## 验收

- 仓库不包含本机绝对环境依赖、密钥、数据库或业务数据。
- 老人端测试、Web构建、Capacitor同步与Android Debug构建可执行。
- 两个小程序分别通过测试、类型检查和 `mp-weixin` 构建。
- 三个后端和共享契约测试保持通过。
